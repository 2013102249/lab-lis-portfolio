## 说明

- 作品集主页包含 5 个板块：项目概览 / 设计文档 / 可审阅 PRD / 综合方案图 / 评测方案。
- 证据分级：`[真实]` 业务 Demo 可点、`[仿真]` 仿真集跑分、`[估算]` 行业推算、`[假设]` 方案设计。
- Demo 数据保存在浏览器 localStorage，主页「重置演示数据」可恢复初始状态。
- 内部讲解材料不在此仓库，禁止对外发布。
